## شنو يسوي البوت

Newsora ينقل الأخبار من قنوات تيليجرام ثانية (**المصادر**) إلى قناتك (**الهدف**) تلقائياً وحسب جدول زمني. وكل شي تديره من لوحة تحكم خاصة داخل البوت.

شلون ينتقل المنشور:

1. تكتب قناتك بالمتغير `TARGET_CHANNEL`، وتضيف قنوات المصادر الي تريد تتابعها من اللوحة. ما ينضاف لك أي شي تلقائياً.
2. حسابك بتيليجرام ينضم للمصادر ويسمع للمنشورات الجديدة (نصوص وصور وفيديوهات وملفات وألبومات).
3. كل منشور جديد ينظّف وينترجم للعربي ويتفحّص: لازم ما يكون مكرر ولازم يعدّي فلاتر الكلمات الي حددتها.
4. المنشورات الي تعدّي تنتظر بطابور. والأخبار العاجلة تتقدم.
5. البوت (أو حسابك) ينشرها بقناتك، ويا فاصل بين المنشورات وضمن الحد اليومي وساعات النشر.

| الميزة | التفاصيل |
|---|---|
| **القراءة** | حسابك الشخصي يقرأ قنوات المصادر (Telethon). يدعم النصوص والصور والفيديوهات والملفات والألبومات |
| **الترجمة للعربي** | سلسلة مزوّدي ذكاء اصطناعي ويا تبديل تلقائي (Gemini وGroq وNVIDIA وOpenRouter وMistral ومزوّد مخصص متوافق مع OpenAI وClaude وOpenAI)، وآخرها Google Translate. والأرقام بالترجمة تنقارن ويا الأصل |
| **منع التكرار** | خمس طبقات: نفس الملف، صورة أو فيديو مشابه (حتى لو أُعيد ترميزه)، نفس النص، نفس الخبر بصياغة أو لغة ثانية، وحكم الذكاء الاصطناعي للحالات الرمادية |
| **العاجل أولاً** | المنشورات الي بيها كلمات عاجل أو كلمات حدث تتقدم بالطابور وتنشر فوراً بترويسة عاجل |
| **وسم خبر غير مؤكد** | المنشورات الي بيها صياغة مثل "يزعم" أو "بحسب مصادر" أو "reportedly" تاخذ وسم "خبر غير مؤكد". وتكدر تحدد قنوات ضعيفة الموثوقية فتاخذ كل أخبارها الوسم |
| **هاشتاقات حسب الموضوع** | تنضاف تلقائياً حسب موضوع المنشور |
| **الفلاتر** | قائمة منع (أي منشور فيه الكلمة يُتجاهل) وقائمة سماح (ينشر فقط المنشور الي فيه وحدة منها) |
| **حذف وتعديل المصدر** | إذا المصدر حذف منشور وهو بالطابور ينحذف عندنا، وإذا عدّله ناخذ النسخة المعدّلة |
| **طريقتين للنشر** | عن طريق البوت، أو عن طريق حسابك (مطلوب للإيموجي المتحرك بالقنوات؛ الحساب لازم Premium وأدمن بالقناة) |
| **تقرير يومي** | ملخص يوصلك بالخاص الساعة 10 مساءً بتوقيت العراق: المنشور والمكرر والمفلتر وحالة كل مزوّد ذكاء |
| **اختياري وتجريبي** | تفريغ كلام الفيديو (ffmpeg وGroq Whisper) وقراءة النص داخل الصور (Gemini Vision). الاثنين مطفيين افتراضياً وممكن يخطون، فجرّبهم على قنوات قليلة أول |

## السلوك الافتراضي

هذي القيم الافتراضية بملف `config.py`، وكلها تتغير من اللوحة.

| الإعداد | الافتراضي |
|---|---|
| الفاصل بين المنشورات | عشوائي بين 30 و90 دقيقة |
| الحد اليومي | 20 منشور |
| ساعات النشر | من 7 إلى 24 بتوقيت العراق (`Asia/Baghdad`) |
| عمر المنشور بالطابور | ساعتين، والأقدم ينحذف حتى لو ما اننشر |
| حجم الطابور | 40 منشور |
| أقل طول للنص | 40 حرف |
| نافذة التكرار | 48 ساعة (سجل البصمات المنشورة يحتفظ بآخر 40 ألف بصمة) |
| قنوات المصادر | ما كو، إنت تضيف قنواتك |
| توقيع المنشورات | ما كو، وتكدر تحدد واحد بـ`POST_SIGNATURE` |
| العاجل فوراً، وسم غير مؤكد، هاشتاقات الموضوع، التقرير اليومي | شغّالة |
| سطر المصدر، تفريغ الفيديو، قراءة نص الصور | مطفية |

## التثبيت

**المتطلبات:** توكن بوت من [@BotFather](https://t.me/BotFather)، و`API_ID` و`API_HASH` من [my.telegram.org](https://my.telegram.org)، وأيدي حسابك الرقمي (تحصله من [@userinfobot](https://t.me/userinfobot))، وقناة البوت أدمن بيها وعنده صلاحية النشر.

### متغيرات البيئة

| المتغير | مطلوب | الوصف |
|---|---|---|
| `API_ID` و`API_HASH` | نعم | من my.telegram.org |
| `BOT_TOKEN` | نعم | من @BotFather |
| `OWNER_ID` | نعم | أيدي حسابك الرقمي. الحساب الوحيد المسموح له بلوحة التحكم |
| `TARGET_CHANNEL` | نعم | **اكتب قناتك هنا**: القناة الي تنتشر بيها المنشورات، بصيغة `@username` أو أيدي رقمي. البوت ما يشتغل بدونها |
| `POST_SIGNATURE` | لا | نص ينضاف تحت كل منشور، مثلاً اسم قناتك ورابطها. استخدم `\n` لسطر جديد |
| `DATA_DIR` | لا | مجلد الإعدادات والسيشن والمفاتيح وسجل التكرار. الافتراضي `data` |
| `SESSION_STRING` | لا | سيشن احتياطي. السيشن المستخرج من اللوحة له الأولوية |
| `MAX_MEDIA_MB` | لا | أكبر حجم ملف وسائط. الافتراضي `100` |
| `GEMINI_API_KEY` و`GROQ_API_KEY` و`NVIDIA_API_KEY` و`OPENROUTER_API_KEY` و`MISTRAL_API_KEY` | لا | مزوّدين مجانيين. تكدر تضيفهم من اللوحة أيضاً |
| `ANTHROPIC_API_KEY` و`OPENAI_API_KEY` | لا | مزوّدين مدفوعين، يُستخدمون آخر شي. و`OPENAI_BASE_URL` لعنوان OpenAI مخصص |
| `CUSTOM_LLM_BASE` و`CUSTOM_LLM_KEY` و`CUSTOM_LLM_MODEL` | لا | أي مزوّد متوافق مع OpenAI |
| `LLM_ORDER` | لا | ترتيب المزوّدين، مثلاً `gemini,groq,nvidia`. الافتراضي: gemini ثم groq ثم nvidia ثم openrouter ثم mistral ثم custom ثم anthropic ثم openai |
| `GEMINI_MODELS` و`GROQ_MODELS` و`WHISPER_MODEL` | لا | أسماء الموديلات مفصولة بفاصلة. غيّرها إذا انحذف موديل من الخطة المجانية |

بدون أي مفتاح ذكاء اصطناعي تبقى الترجمة شغالة عن طريق Google Translate.

### التشغيل محلياً

```bash
python -m venv .venv
source .venv/bin/activate        # على ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
```

سوّي ملف `.env` من `.env.example`، وحمّل قيمه كمتغيرات بيئة، بعدها:

```bash
python main.py
```

ثبّت `ffmpeg` فقط إذا تريد تفريغ كلام الفيديو.

### النشر على Railway

1. ارفع المشروع إلى مستودع GitHub (لا ترفع `.env` ولا `data/` أبداً).
2. بـRailway اختار **New Project ← Deploy from GitHub repo**. ملف `Procfile` يشغّل الـworker (`python main.py`) وملف `nixpacks.toml` يثبّت ffmpeg.
3. ضيف `API_ID` و`API_HASH` و`BOT_TOKEN` و`OWNER_ID` و`TARGET_CHANNEL` من **Variables**.
4. **مهم:** سوّي **Volume** واربطه بخدمة البوت على المسار `/data`، وضع `DATA_DIR=/data`. بدونه كل نشر جديد يمسح السيشن والمفاتيح والإعدادات وسجل التكرار. إذا ظهر خطأ صلاحيات ضيف `RAILWAY_RUN_UID=0`.
5. النشر الجديد يسبب توقف قصير، وما تكدر تشغّل نسختين من الخدمة ويا Volume واحد.

## اكتب قناتك ومصادرك

- **قناتك (الي تنتشر بيها المنشورات):** اكتبها بـ`TARGET_CHANNEL` مثل `TARGET_CHANNEL=@your_channel_here`، أو استخدم الأيدي الرقمي لها. ضيف البوت للقناة كأدمن ويا صلاحية النشر. وإذا تنشر عن طريق حسابك، لازم الحساب أدمن بالقناة أيضاً.
- **قنوات المصادر (الي تنأخذ منها الأخبار):** ما كو أي مصدر افتراضي. من اللوحة اضغط **المصادر** ثم **إضافة مصدر**، وأرسل كل قناة بصيغة يوزر (`@name`) أو رابط `t.me/name` أو أيدي رقمي. تكدر ترسل عدة قنوات بنفس الرسالة، كل وحدة بسطر. إذا حساب القارئ متصل، ينضم لها تلقائياً بفاصل 3 إلى 7 ثواني حتى تجنب قيود تيليجرام. روابط الدعوة الي تبدأ بـ`+` ما تنقبل. وللقناة الخاصة الي حسابك منضم إلها، أرسل أيديها الرقمي.
- **حذف مصدر:** اضغط **المصادر** ثم **حذف مصدر**، وأرسل رقمه من القائمة أو يوزره.

## أول تشغيل

1. افتح البوت من حسابك وأرسل `/start`. اللوحة تشتغل فقط لـ`OWNER_ID`.
2. **استخراج سيشن:** اختار بالرقم أو عبر QR، بعدها تفعيل. بالرقم، اكتب الكود مفصول بشرطات مثل `1-2-3-4-5` حتى تيليجرام ما يبطله. وبـQR افتح تيليجرام من جهاز ثاني، الإعدادات، الأجهزة، ربط جهاز، وامسح الصورة.
3. **الذكاء الاصطناعي** (اختياري): ضيف مفتاح Gemini ومفتاح Groq، الاثنين مجانيين، بعدها اضغط زر الفحص الحقيقي.
4. **المصادر:** ضيف القنوات الي تريد تتابعها (شوف القسم الي فوق). ولو تريد تنضم بحسابك لكلها من جديد، اضغط زر الانضمام.
5. اضغط **فحص شامل**. يرسل رسالة صامتة للقناة ويحذفها، حتى يتأكد أن النشر شغّال.

## لوحة التحكم

أرسل `/start` أو `/panel` للبوت بالخاص. و`/cancel` يلغي الخطوة الحالية.

| الزر | وظيفته |
|---|---|
| الحالة | اتصال القارئ والطابور والعدد اليومي وآخر نشر والمكرر المتجاهل وآخر خطأ |
| فحص شامل | اختبار حقيقي للنشر والمزوّدين وffmpeg |
| إيقاف أو تشغيل النشر | يوقف النظام كله ويرجعه |
| المصادر | إضافة وحذف مصدر، وانضمام الحساب للقنوات |
| الإعدادات | الترجمة تشغيل أو إيقاف، النشر عبر البوت أو الحساب، الفاصل، الحد اليومي، عمر الخبر، الساعات |
| استخراج سيشن | دخول بالرقم أو QR، تفعيل، عرض أو حذف السيشن المحفوظ |
| نشر فوري | ينشر أحدث منشور بالطابور خلال ثواني |
| الذكاء الاصطناعي | مفاتيح المزوّدين وفحص حقيقي لكل واحد |
| ميزات ذكية | مفاتيح للعاجل ووسم غير مؤكد وسطر المصدر والهاشتاقات وتفريغ الفيديو ونص الصور والتقرير اليومي |
| الفلاتر | كلمات ممنوعة وكلمات مطلوبة ومصادر غير موثّقة |
| إعادة تشغيل القارئ | يعيد اتصال الحساب القارئ |

## ملفات المشروع

| الملف | وظيفته |
|---|---|
| `main.py` | تشغيل البوت واللوحة والمحرك |
| `engine.py` | القارئ والطابور وفحص التكرار والترجمة والنشر |
| `panel.py` | لوحة التحكم الخاصة بالمالك |
| `login.py` | استخراج السيشن بالرقم أو QR |
| `llm.py` | سلسلة مزوّدي الذكاء الاصطناعي ويا التبديل التلقائي |
| `textproc.py` | تنظيف النص والترجمة وبناء الكابشن |
| `filters.py` | درجة العاجل وكشف غير المؤكد وفلاتر الكلمات وهاشتاقات الموضوع |
| `dedupe.py` | كشف التكرار |
| `media.py` | تفريغ الفيديو وقراءة نص الصور |
| `emojis.py` | دعم الإيموجي المتحرك |
| `store.py` | تخزين الإعدادات والسيشن والمفاتيح والبصمات |
| `config.py` | متغيرات البيئة والتوقيع والهاشتاقات الافتراضية |

لو تريد توقّع كل منشور، حدد `POST_SIGNATURE`. ولتغيير الهاشتاقات الافتراضية، عدّل `HASHTAGS` بملف `config.py`.

Newsora يعيد نشر محتوى من قنوات ثانية. إنت الي تختار المصادر، وإنت المسؤول عن الي تنشره، وعن احترام حقوق النشر وشروط تيليجرام، وعن دقة الأخبار. فعّل سطر المصدر من الميزات الذكية إذا تريد تذكر من وين جا كل منشور. استخدم حسابك الشخصي للقارئ وخلي سيشنه سري. طريقة الإبلاغ عن ثغرة بملف [SECURITY.md](SECURITY.md).
